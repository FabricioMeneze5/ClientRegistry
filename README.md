# 📖 ClientRegistry

### 📌 Description

**ClientRegistry** is a simple Java application to manage client information. It allows users to perform basic CRUD (Create, Read, Update, Delete) operations. The data is stored in memory using a `HashSet`, and the user interface is built with `JFrame`.

---

### 🛠️ Tecnologias | Technologies

- Java
- Swing (JFrame, JTable, JOptionPane)
- NetBeans IDE
- Git and GitHub

---

### 🎨 Features

- Add a new client
- Edit client information
- Delete clients
- View all clients in a table
- Alerts for user actions (success, errors, confirmations)
